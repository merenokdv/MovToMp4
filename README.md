# MovToMp4

Локальный конвертер видео **MOV → MP4**. Файлы обрабатываются на твоём Mac через `ffmpeg` и никуда не отправляются.

## Требования

- macOS
- Python 3
- [ffmpeg](https://ffmpeg.org/)

Установка ffmpeg:

```bash
brew install ffmpeg
```

## Запуск интерфейса

Самый простой способ — двойной клик по файлу:

```text
start.command
```

Или из терминала:

```bash
cd /Users/vortimen/develop/MovToMp4
python3 app.py
```

Откроется браузер: [http://127.0.0.1:8765](http://127.0.0.1:8765)

## Как пользоваться (веб-интерфейс)

1. Перетащи `.mov` в область загрузки или нажми и выбери файл.
2. Выбери режим конвертации (см. ниже).
3. Дождись прогресса.
4. Нажми **Скачать MP4** или **Открыть папку** — готовые файлы лежат в `output/`.

Можно кидать несколько файлов подряд.

## Режимы конвертации

| Режим | Что делает | Когда брать |
| --- | --- | --- |
| **Мгновенно** (`copy`) | Копирует потоки без перекодирования | Почти всегда для записей экрана / iPhone |
| **Быстро** (`fast`) | Перекодирует через VideoToolbox | Если «Мгновенно» не подошло |
| **Качество** (`quality`) | Перекодирует через x264 | Нужен максимальный контроль качества |

Если режим «Мгновенно» не сработал (несовместимые кодеки), приложение само переключится на быстрое перекодирование.

## Конвертация из терминала

```bash
# Рядом с исходником появится .mp4
python3 convert.py video.mov

# С выбором режима и пути
python3 convert.py video.mov -m fast -o output/video.mp4
```

Параметры:

- `-m copy|fast|quality` — режим (по умолчанию `copy`)
- `-o путь.mp4` — куда сохранить результат
